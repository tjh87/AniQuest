# Do and do not

| Area | Do | Do not |
| --- | --- | --- |
| Existing work | Extend recovered code; preserve IDs, content and saves | Replace with a small demo or fresh scaffold |
| Runtime | Keep local Vite build and loopback server | Require Sites, login, API keys or remote DB to launch |
| Windows | Quote paths; retain lockfile and native launchers | Assume Bash/WSL; ship Linux development dependencies |
| Offline | Package runtime assets; label absent media | Add CDNs, remote fonts, hidden analytics or silent downloads |
| Photos | Real full-frame images, original aspect, alt text, credits | Crop animals, pixelate photos, generate evidence, invent reuse rights |
| Graphs | Cytoscape, independent border/line/arrow tokens, curves, working targets | Identical outlines/lines, clipped arrowheads, hidden default graph |
| Meaning | Distinguish taxonomy from broad browsing matches | Imply ancestry, genetic distance or close kinship from shared habitat |
| Sections | Expanded initially; remember explicit manual choices | Reset preferences every render or lose graph after collapse |
| Spacing | Compact gaps, readable text, adequate touch targets | Tiny type, overlapping controls or giant empty panels |
| Locations | Source-supported habitat and occurrence qualifiers | Invent parks, promise sightings, reveal sensitive dens/nests |
| Biology | Separate national/global status, origin and uncertainty | Treat unassessed as Least Concern or global as Singapore status |
| Learning | Six valid guided checks per profile; versioned evidence | Invent unanswered results, inflate retries, duplicate XP |
| Saves | Validate versioned data and report failures | Overwrite unreadable saves or treat local storage as secure accounts |
| Calendar | Distinguish dated sessions, seasonal patterns and undated listings | Invent dates or call a stale snapshot live |
| Sources | Claim-level evidence and truthful change records | Approve facts from HTTP 200 or fabricate reviewers/dates |
| Accessibility | Native buttons, keyboard/focus, reduced motion | Canvas-only controls or bitmap-only labels |
| Dependencies | Existing tools/lockfile; official upgrade docs | Overlapping graph/lightbox frameworks or wholesale upgrade during export |
| Admin | Keep explicit server boundary | Fake admin/user state or expose protected endpoints to look complete |
| Secrets | Placeholders; private data outside Git/ZIP | Tokens, environment secrets, browser saves, database dumps |
| Release | Extract/verify package and report actual results | Claim native Windows QA or successful push without evidence |
| Publishing | Honour current authorization and remote history | Deploy to Sites by default, force-push or change repository visibility |

These document product intent; they do not override current user instructions or access controls.
