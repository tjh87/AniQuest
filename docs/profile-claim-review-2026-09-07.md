# Profile claim review — 7 September 2026

Reviewed 49 profiles and 539 tracked claims. Added 538 review records.

339 claims have source support. 200 claims still need evidence. No unresolved claim was labelled verified.

The review covers identification, diet, activity, behaviour, Singapore occurrence, reproduction, ecological role, pressures, viewing advice, national status and global status. It does not certify every untracked sentence or photograph.

The review compared NParks profile pages and RDB3 tables, AVS guidance, Animal Diversity Web, NOAA, local research papers and specialist bird sources. Retrieval alone did not count as verification.

Many global assessment pages blocked access. Some profiles already withhold global assessments. Other gaps involve details beyond the inspected source text, or claims that combine several sources.
